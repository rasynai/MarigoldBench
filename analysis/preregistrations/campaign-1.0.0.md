# CRUCIBLE campaign preregistration - 1.0.0 (release campaign)

- Registered: 2026-08-15, before any 1.0 model call (no
  runs/release-1.0.0/systems/*/outcomes file existed at registration).
- Sponsor: Ansh Tiwari. Standing scope: model experts + simulator only; no
  humans, no labs, ever (docs/LIMITATIONS.md).

## Task population (frozen at registration)

Generated by `crucible.taskgen` (registry/generated_task_index.json):
30 templates / 10 archetypes / 104 instances. Conditions per template:
N0 clean, N1 planted consequential hazard, N2 underidentified. Splits:
16 development (public), 66 hidden_test, 22 sealed (tasks_sealed/,
git-ignored, excluded from the release build). Honest clustering: ARCHETYPE is
the top source cluster; templates within an archetype are correlated. Sealed
means "not in the public repo tree", not "unknown to the generator author".

## Systems and run plan

- 8 API reference-agent systems: claude-opus-5, gpt-5.6-sol, and 6 OpenRouter
  flagships (gemini-3.7-flash, grok-4.6, deepseek-v4-pro, qwen3.8-max,
  kimi-k3, glm-5.2). Each: every hidden instance once, every sealed instance
  once, plus 2 extra repeat runs on the first 6 hidden instances (deterministic
  order) for run-to-run variance. 100 runs/system.
- marigold (native product): random-but-seeded subset (seed 1000): 20 hidden +
  8 sealed, once each, 18-min budget.

## Primary outcome

Hidden-set reliable completion (first run per instance), per system, with
archetype-cluster bootstrap intervals. Secondary: per-condition rates (N0/N1/
N2), sealed rates and hidden-vs-sealed gap, repeat flip rate, judge-agreement
sample (6/system, cross-family, advisory), criterion-validity correlation of
hidden RCR against Tracks D/E simulator results across systems.

## Rules

- No exclusions after outcomes are seen; failed runs (API errors after
  retries, no-submission) are failures.
- Restartable per (system, instance, run); reruns never overwrite an existing
  outcome file.
- Cost guard: CRUCIBLE_MAX_CALLS=6000 total ledger entries aborts everything.
- Prohibited claims: all prior prohibitions; additionally no
  "contamination-proof" claim - the sealed split probes repo-level exposure
  only, and every instance shares the generator author.

## Stop rules

Sponsor stop; truth-boundary violation aborts; cost guard aborts.
